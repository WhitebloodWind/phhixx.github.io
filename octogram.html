Octogram

Project / Fall 2024
The Brief

Octogram is my raspberry pi home server. This project is a deep dive into networking and server management. Utilizing a Raspberry PI with Open Media Vault (OMV) to build a centralied storage solution.

This project used a Penta SATA hat from Radxa, it utilizes the PCIE port on the Pi 5 to connect SATA ssds. The AI bubble caused all pc hardware to skyrocket in price, it was fortunate that I still managed to get the ssds required.

Currently, Octogram has 2 ssds while it can hold up to 4 and also an external one. It also uses an active cooler which is screwed in and powered by the 5V GPIO pin.

Project inspired by Jeff Geerling and Michael Klements.
